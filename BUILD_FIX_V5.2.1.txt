BountyOS v5.2.1 Cloud Build fix

Cause:
- Builder used golang:1.24-bookworm.
- httpx v1.9.0 requires Go 1.25+ (the failed build specifically required >=1.25.7).

Fix:
- Builder pinned to golang:1.25.11-bookworm.
- Tool versions pinned for reproducible builds.
- GOTOOLCHAIN=auto enabled.
- Katana built with CGO_ENABLED=1; other Go CLI tools built with CGO_ENABLED=0.
